# Camera Example Design (RTL)

This branch contains an archive of the RTL line, which has been superseded by the current Camera Example Design:

- **RTL**: Custom RTL gateware + C++/wxWidgets desktop software
- **Current**: AMD Video IP (IPI block designer) gateware + JavaScript/web (FP-Platform) software

This is an archived design provided AS-IS as a community resource. Opal
Kelly does not officially maintain this asset or provide technical support
for issues arising from its use. As this code is not actively maintained,
it may fall out of date with newer tools, SDKs, or operating systems.
